# 👨‍💻 Ismail Maeen - AI & Data Science Portfolio Website

## 🌐 Overview
This is a **personal portfolio website** for **Ismail Maeen**, an AI and Data Science engineer.  

The website serves as an interactive showcase of his **education, certifications, projects, skills, services, and resume**, providing visitors with a clear and professional overview of his expertise.  

**Live Website:** [https://ismailmaeen.com/](https://ismailmaeen.com/)

---

## 🚀 Features

### 🌟 Frontend Features
- **About Me** — Personal information, professional summary, and contact details.  
- **Education & Certifications** — Detailed display of academic background, courses, and certificates.  
- **Projects** — Portfolio of key projects with categories, technologies used, and links where applicable.  
- **Services** — Overview of services offered, including AI, data analytics, and application development.  
- **Resume** — Interactive resume with professional experience, skills, and additional competencies.  
- **Skills Section** — Highlighting technical skills, programming languages, frameworks, and tools.  
- **Responsive Design** — Optimized for all devices including desktop, tablet, and mobile.  
- **Modern UI** — Clean, professional, and user-friendly interface.

---

### 🏢 Admin / Management Features
- Fully manageable content via backend (if applicable) to update projects, services, and personal information.  
- Dynamic filtering of projects by category for improved user experience.  
- Resume and skills are dynamically loaded from structured data (JSON or database).
